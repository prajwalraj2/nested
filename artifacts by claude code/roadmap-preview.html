What this prototype is demonstrating

The role dropdown navigates
Each role is its own Page row, so switching changes the URL above — that is what makes one role shareable.
Not every topic is clickable
Azure, GCP and AKS have no content. They are labels on the spine, and deliberately have no hover state or pointer.
Topics deep-link
Opening one appends ?topic=. On the real site the server renders that sheet already open, so the content is in the HTML and indexable.
Sub-topic chips swap in place
The sheet stays open and the content changes — moving through a topic rather than bouncing out and back in.
Docker appears twice
Once under Backend, once under DevOps, as two independent rows. Duplication is the agreed design; shared nodes make ordering ambiguous.
Content follows the theme
Try the Theme button. This only works because the stored HTML carries no inline colour — which the sanitiser has to enforce, not the editor.
